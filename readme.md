## ТЕХНИЧЕСКОЕ ЗАДАНИЕ## Разработка Telegram-бота для инвентаризации ИТ-оборудования по фото шильдиков (наклеек)## 1. Общие сведения

* 
* Наименование системы: IT-Asset-OCR-Bot
* Назначение: Автоматизация сбора серийных номеров, сервисных тегов и моделей мониторов/ПК по фотографиям заводских наклеек (шильдиков) для последующей инвентаризации.
* Целевая аудитория: Системные администраторы, инженеры технической поддержки, сотрудники склада.
* 

------------------------------
## 2. Функциональные требования## 2.1. Интерфейс взаимодействия

* 
* Взаимодействие осуществляется через мессенджер Telegram.
* Бот принимает от пользователя сообщения двух типов:
1. Изображение (Photo) — одиночная фотография наклейки оборудования напрямую со смартфона.
   2. Документ (Document) — фотография, отправленная без сжатия (для сохранения максимального качества).
* При старте команды /start бот выводит приветственное сообщение с краткой инструкцией: «Отправьте мне четкое фото наклейки на мониторе/ПК, и я пришлю вам данные для копирования».
* 

## 2.2. Логика обработки и распознавания (Двухэтапный контур OCR)
Бот должен использовать гибридную схему обработки изображений во избежание избыточной нагрузки на сервер.

       [Пользователь отправляет фото]
                     │
                     ▼
       ┌───────────────────────────┐
       │ Контур 1: EasyOCR (Питон) │
       └─────────────┬─────────────┘
                     │
        Удалось распарсить регулярками?
                     ├───► ДА ──► [Выдать результат]
                     │
                     ▼ НЕТ
       ┌───────────────────────────┐
       │ Контур 2: Llama 3.2 Vision│ (Локально через Ollama)
       └─────────────┬─────────────┘
                     │
                     ▼
              [Выдать результат]

## Контур №1: Легковесный локальный OCR (EasyOCR / Tesseract)

* 
* При получении фото запускается библиотека EasyOCR (или Pytesseract) в связке с OpenCV для предварительной фильтрации (бинаризация, контраст).
* Из полученного массива сырого текста скрипт пытается вычленить данные с помощью Регулярных выражений (RegEx):
* Шаблон Dell: Service Tag:\s*([A-Z0-9]{7})
   * Шаблон S/N: S/N:\s*([A-Z0-9-]+)
* Если регулярные выражения успешно отработали и нашли ключевые поля (Модель и Серийный номер), бот сразу переходит к этапу выдачи ответа (экономия ресурсов CPU/GPU).
* 

## Контур №2: Локальная нейросеть (Llama 3.2 Vision)

* 
* Если Контур №1 вернул ошибку, не нашел ключевых слов или текст оказался слишком искажен, изображение передается во второй контур.
* Бот отправляет изображение на локальный сервер ИИ через API-инструмент Ollama (модель llama3.2-vision:11b или 3b).
* Модели передается строгое системное руководство (Промпт):

"Ты — ассистент системного администратора. Твоя задача — внимательно изучить изображение наклейки ИТ-оборудования. Найди и извлеки следующие параметры: Производитель (Brand), Модель (Model), Серийный номер (S/N или Serial Number), Сервисный тег (Service Tag, только для Dell). Верни ответ СТРОГО в формате JSON с ключами: brand, model, serial_number, service_tag. Если поле не найдено, напиши null. Никакого лишнего текста в ответе быть не должно."

* 

## 2.3. Требования к выводу информации
Бот должен присылать структурированное сообщение, оптимизированное для быстрого копирования на смартфоне (использование моноширинного шрифта):

🖥 Оборудование успешно распознано!
• Производитель: Dell
• Модель: E2722H
• Серийный номер: CN0Y71R3TV20019B13QT
• Service Tag: 9YSCSF3
(Нажмите на значение, чтобы скопировать его в буфер обмена)

## 3. Технический стек и архитектура

* 
* Язык программирования: Python 3.10+
* Фреймворк Telegram: aiogram 3.x (асинхронный, обеспечивает высокую скорость при параллельных запросах).
* Контур 1 (Скан): EasyOCR + opencv-python (для базовой предобработки картинок).
* Контур 2 (ИИ): Локально развернутый движок Ollama с загруженной моделью llama3.2-vision. В коде интеграция реализуется через официальную библиотеку ollama-python.
* База данных (Опционально): SQLite для логирования действий пользователей и сохранения истории сканирований.
