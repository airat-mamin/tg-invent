# Установка и запуск IT-Asset-OCR-Bot

Реализация MVP по [техническому заданию](../readme.md). Текущий объём: этапы 1, 2, 5, 6 ТЗ
(каркас бота, контур штрихкодов, карточка с подтверждением, БД и выгрузка), а также каркасы
контуров №1 (EasyOCR) и №2 (Llama 3.2 Vision), которые включаются флагами конфигурации.

## Что уже работает

| Возможность | Статус |
| --- | --- |
| Приём фото и файлов-изображений, `/start`, `/help`, `/last`, `/export`, `/stats`, `/cancel` | ✅ |
| Контур №0 — штрихкоды Code128/Code39/QR/DataMatrix | ✅ |
| Контур №1 — EasyOCR + RegEx + поиск по соседству блоков | ✅ (включается `OCR_ENABLED`) |
| Контур №2 — Llama 3.2 Vision через Ollama | ✅ (включается `VLM_ENABLED`, нужен GPU) |
| Нормализация, валидация, подбор визуально схожих символов, уровни доверия | ✅ |
| Карточка с копированием по нажатию, подтверждение и ручная правка | ✅ |
| SQLite, дедупликация, экспорт CSV/XLSX | ✅ |
| Контроль доступа по белому списку, антифлуд | ✅ |

Не входит в MVP: веб-интерфейс, интеграции с учётными системами, распознавание нескольких
наклеек на одном снимке, периодическая очистка изображений по расписанию (сейчас выполняется
при старте).

## Быстрый старт без Docker

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt          # ядро: контуры №0 и №2
pip install -r requirements-ocr.txt      # опционально: контур №1 (EasyOCR + torch)

cp .env.example .env
# укажите BOT_TOKEN и ALLOWED_USER_IDS

python -m app.main
```

Свой Telegram ID можно узнать у бота `@userinfobot`.

## Запуск в Docker

```bash
cp .env.example .env          # заполните BOT_TOKEN и ALLOWED_USER_IDS
docker compose up -d --build  # без EasyOCR

WITH_OCR=true docker compose up -d --build   # с контуром №1
```

Для контура №2 после первого запуска нужно загрузить модель:

```bash
docker compose exec ollama ollama pull llama3.2-vision:11b
```

и выставить `VLM_ENABLED=true` в `.env`. Без GPU (≥10 ГБ VRAM) контур №2 включать не стоит:
время ответа выйдет далеко за целевые 30 секунд из ТЗ.

## Конфигурация

Все параметры описаны в `.env.example`. Ключевые:

| Переменная | Значение по умолчанию | Комментарий |
| --- | --- | --- |
| `BOT_TOKEN` | — | Обязательна |
| `ALLOWED_USER_IDS` | пусто | **Пустое значение открывает бота всем.** Заполните перед эксплуатацией |
| `ADMIN_USER_IDS` | пусто | Доступ к `/stats` и выгрузке всех записей |
| `OCR_ENABLED` | `true` | Если EasyOCR не установлен, контур отключается сам с предупреждением в логе |
| `VLM_ENABLED` | `false` | Включать только при наличии GPU |
| `STORE_IMAGES` | `false` | Хранение исходных фото; удаляются через `IMAGE_RETENTION_DAYS` |
| `RATE_LIMIT_PER_MINUTE` | `10` | Лимит изображений на пользователя |

## Тесты и линтер

```bash
pip install -r requirements-dev.txt
pytest -q
ruff check app tests
```

Тесты покрывают нормализацию и валидацию значений, регулярные выражения, разбор ответа VLM,
парсинг блоков OCR и сквозной прогон контура штрихкодов на синтетических изображениях
(штрихкод генерируется и тут же декодируется).

## Безопасность

* Токен хранится только в `.env`, файл в `.gitignore`.
* Если токен попадал в переписку или репозиторий, отзовите его командой `/revoke` у `@BotFather`.
* Все данные обрабатываются локально, изображения во внешние сервисы не передаются.
